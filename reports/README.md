# Reports Boundary

This public repository keeps only analytical outputs that are consistent with the current evidence-first methodology.

Older scratch notes, reports that reproduced social-media post text, and visualizations generated from superseded causal framing are intentionally excluded from the public branch.

## Current reporting standard

Public reports should:

- distinguish description, correlation, and causal evidence
- cite original data sources and collection dates
- document sampling and comparability limits
- avoid treating technical exposure as proof of job displacement
- avoid treating survey sentiment as an objective learning outcome
- avoid republishing unnecessary user-generated text
- avoid personal working notes, private paths, credentials, and internal project-management material

The README summarizes current provisional findings. New report artifacts should be added only after their methods, provenance, and limitations are documented.
